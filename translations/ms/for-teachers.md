## Untuk Pendidik

Adakah anda ingin menggunakan kurikulum ini di dalam kelas anda? Sila teruskan!

Malah, anda boleh menggunakannya terus dalam GitHub dengan menggunakan GitHub Classroom.

Untuk berbuat demikian, buatlah fork repositori ini. Anda perlu mencipta repositori untuk setiap pelajaran, jadi anda perlu mengeluarkan setiap folder ke dalam repositori berasingan. Dengan cara itu, [GitHub Classroom](https://classroom.github.com/classrooms) boleh mengesan setiap pelajaran secara berasingan.

[Arahan penuh](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) ini akan memberi anda idea bagaimana untuk menyediakan kelas anda.

## Menggunakan repositori seperti sedia ada

Jika anda ingin menggunakan repositori ini seperti sekarang, tanpa menggunakan GitHub Classroom, itu juga boleh dilakukan. Anda perlu berkomunikasi dengan pelajar anda pelajaran mana yang akan diikuti bersama.

Dalam format dalam talian (Zoom, Teams, atau lain-lain) anda mungkin membentuk bilik pecahan untuk kuiz, dan membimbing pelajar untuk membantu mereka bersedia belajar. Kemudian jemput pelajar untuk mengambil kuiz dan menghantar jawapan mereka sebagai 'isu' pada masa tertentu. Anda juga boleh melakukan perkara yang sama dengan tugasan, jika anda mahu pelajar bekerja secara kolaboratif secara terbuka.

Jika anda lebih suka format yang lebih peribadi, minta pelajar anda untuk membuat fork kurikulum, pelajaran demi pelajaran, ke repositori GitHub mereka sendiri sebagai repositori peribadi, dan beri anda akses. Kemudian mereka boleh menyiapkan kuiz dan tugasan secara peribadi dan menghantarnya kepada anda melalui isu pada repositori kelas anda.

Terdapat banyak cara untuk menjadikan ini berfungsi dalam format kelas dalam talian. Sila beritahu kami apa yang paling berkesan untuk anda!
