# Model pengelompokan untuk pembelajaran mesin

Pengelompokan adalah tugas pembelajaran mesin di mana ia mencari objek yang serupa antara satu sama lain dan mengelompokkan ini ke dalam kumpulan yang dipanggil kluster. Apa yang membezakan pengelompokan daripada pendekatan lain dalam pembelajaran mesin, adalah bahawa ia berlaku secara automatik, sebenarnya, boleh dikatakan ia adalah sebaliknya daripada pembelajaran terawasi.

## Topik rantau: model pengelompokan untuk citarasa muzik audien Nigeria 🎧

Audien yang pelbagai di Nigeria mempunyai citarasa muzik yang pelbagai. Dengan menggunakan data yang diambil dari Spotify (diilhamkan oleh [artikel ini](https://towardsdatascience.com/country-wise-visual-analysis-of-music-taste-using-spotify-api-seaborn-in-python-77f5b749b421), mari lihat beberapa muzik yang popular di Nigeria. Set data ini termasuk data tentang skor 'danceability', 'acousticness', kekuatan suara, 'speechiness', populariti dan tenaga pelbagai lagu. Ia akan menarik untuk menemui corak dalam data ini!

Dalam siri pelajaran ini, anda akan menemui cara baru untuk menganalisis data menggunakan teknik pengelompokan. Pengelompokan amat berguna apabila set data anda tidak mempunyai label. Jika ia mempunyai label, maka teknik klasifikasi seperti yang anda pelajari dalam pelajaran sebelum ini mungkin lebih berguna. Tetapi dalam kes di mana anda ingin mengelompokkan data tanpa label, pengelompokan adalah cara yang baik untuk menemui corak.

> Terdapat alat berkod rendah yang berguna yang boleh membantu anda belajar tentang bekerja dengan model pengelompokan. Cuba [Azure ML untuk tugasan ini](https://docs.microsoft.com/learn/modules/create-clustering-model-azure-machine-learning-designer/?WT.mc_id=academic-77952-leestott)
