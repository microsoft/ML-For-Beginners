## 교육자를 위한 안내

이 커리큘럼을 교실에서 사용하고 싶으신가요? 자유롭게 이용하세요!

실제로 GitHub Classroom을 사용하여 GitHub 내에서 직접 사용할 수 있습니다.

그렇게 하려면 이 저장소를 포크하세요. 각 수업에 대해 별도의 저장소를 만들어야 하므로 각 폴더를 별도의 저장소로 분리해야 합니다. 그렇게 하면 [GitHub Classroom](https://classroom.github.com/classrooms)이 각 수업을 개별적으로 인식할 수 있습니다.

이러한 [전체 지침](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/)을 통해 교실 설정 방법을 알 수 있습니다.

## 현재 상태로 저장소 사용하기

GitHub Classroom을 사용하지 않고 현재 상태의 저장소를 사용하고자 한다면 그것도 가능합니다. 학생들과 어느 수업을 함께 진행할지 소통해야 합니다.

온라인 형식(Zoom, Teams 등)에서는 퀴즈를 위해 브레이크아웃 룸을 만들고 학생들을 멘토링하여 학습 준비를 도울 수 있습니다. 그런 다음 학생들에게 퀴즈를 풀고 지정된 시간에 '이슈'로 답안을 제출하도록 초대하세요. 협업이 필요한 과제도 같은 방식으로 진행할 수 있습니다.

더 사적인 형식을 선호한다면 학생들에게 커리큘럼을 수업별로 포크하여 개인 GitHub 저장소(비공개)로 만들고, 당신에게 접근 권한을 주도록 하세요. 그런 다음 학생들은 퀴즈와 과제를 비공개로 완료하고 교실 저장소의 이슈를 통해 제출할 수 있습니다.

온라인 교실 형식에서 이를 실현할 수 있는 방법은 많습니다. 어떤 방법이 가장 좋은지 알려주세요!
