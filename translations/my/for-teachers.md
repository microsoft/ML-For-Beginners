## ဆရာများအတွက်

သင်၏စာသင်ခန်းတွင် ဤသင်ရိုးညွှန်းတမ်းကို အသုံးပြုလိုပါသလား? လွတ်လပ်စွာအသုံးပြုနိုင်ပါသည်!

အမှန်တော့ GitHub Classroom ကို အသုံးပြု၍ GitHub မှာ တိုက်ရိုက်အသုံးပြုလို့ရပါတယ်။

အဲဒါအတွက် ဤ repo ကို fork လုပ်ပါ။ သင်တန်းတိုင်းအတွက် repo အသစ်တစ်ခုဖန်တီးရန် လိုအပ်လိမ့်မည်၊ ဒါကြောင့် ဖိုလ်ဒါတိုင်းကို သီးသန့် repo ဖြစ်အောင် ခွဲထုတ်ရပါမယ်။ အဲဒီလိုလုပ်ရင် [GitHub Classroom](https://classroom.github.com/classrooms) က သင်ခန်းစာတိုင်းကို သီးသန့် ခွဲစီထားနိုင်ပါတယ်။

ဤ [ပြည့်စုံသောညွှန်ကြားချက်များ](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) က သင်၏စာသင်ခန်းကို တွဲဖက်ထားပုံကို သိရှိနိုင်ပါလိမ့်မယ်။

## ဒီ repo ကို အာရုံစိုက်အသုံးပြုခြင်း

GitHub Classroom မသုံးပဲ ဒီ repo ကို လက်ရှိရှိသည့်အတိုင်း အသုံးပြုလိုပါကလည်း ဖြစ်နိုင်ပါသည်။ သင်တန်းသားများအား မည်သည့်သင်ခန်းစာကို တွဲဖက်လေ့လာမည်ဆိုသည်ကို ဆက်သွယ်ပြောကြားရပါမည်။

အွန်လိုင်း ပုံစံ (Zoom, Teams သို့မဟုတ် အခြား) တွင် ကွဲထွက်အခန်းများဖွဲ့၍ မေးခွန်းများလုပ်၊ သင်တန်းသားများကို လေ့လာရန် အသင့်ရှိစေရန် အကြံဉာဏ်ပေးနိုင်သည်။ ထို့နောက် သင်တန်းသားများကို မေးခွန်းများ ဖြေဆိုခွင့်နှင့် သူတို့၏ဖြေကြောင်းများကို သတ်မှတ်အချိန်တွင် 'issues' အဖြစ် တင်ပြရန် ဖိတ်ခေါ်နိုင်ပါသည်။ သင်တန်းသားများအဖွဲ့လိုက်ပူးပေါင်း၍ အလုပ်လုပ်ရန်လိုလျှင်လည်း အဆိုပါ နည်းလမ်းကို အလားတူသုံးနိုင်သည်။

ပုဂ္ဂလိက ပုံစံပို မိုက်မြတ်သည့် သင်ပုဒ်မတစ်ခုဖြစ်ခဲ့လျှင်၊ သင်တန်းသားများကို သင်ရိုးညွှန်းတမ်းကို သင်ခန်းစာခြားစီ ဖေါ့်ခ်၍ သူတို့၏ GitHub repo များကို ပုဂ္ဂလိက တစ်ဆင့် ဖန်တီးပေး၍ သင်အား ဝင်ကြည့်ခွင့်ပေးရန် တောင်းဆိုပါ။ ထို့နောက် သူတို့သည် မေးခွန်းများနှင့် အလုပ်များကို ပုဂ္ဂလိက ဖြေဆိုပြီး သင်၏ စာသင်ခန်း repo တွင် issues အဖြစ် တင်ပြနိုင်ပါသည်။

အွန်လိုင်းစာသင်ခန်း ပုံစံ အတွက် အလုပ်ထွက်စေဖို့ နည်းလမ်းစုံတစ်ဝိုက် ရှိပါသည်။ သင့်အတွက် အကောင်းဆုံးဖြစ်သော နည်းလမ်းကို ကျေးဇူးပြု၍ ပြောပြပါ!
