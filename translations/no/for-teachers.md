## For lærere

Vil du bruke dette pensumet i klasserommet ditt? Vær så god!

Faktisk kan du bruke det direkte i GitHub ved å bruke GitHub Classroom.

For å gjøre det, fork dette repoet. Du må lage et repo for hver leksjon, så du må trekke ut hver mappe til et eget repo. På den måten kan [GitHub Classroom](https://classroom.github.com/classrooms) hente hver leksjon separat.

Disse [fullstendige instruksjonene](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) vil gi deg en idé om hvordan du setter opp klasserommet ditt.

## Bruke repoet som det er

Hvis du ønsker å bruke dette repoet som det står, uten å bruke GitHub Classroom, kan det også gjøres. Du må da kommunisere med studentene dine hvilken leksjon dere skal gå gjennom sammen.

I et nettformat (Zoom, Teams eller annet) kan du opprette grupperom til quizene, og veilede studentene for å hjelpe dem å bli klare til å lære. Deretter kan du invitere studentene til å ta quizene og sende inn svarene som 'issues' på et avtalt tidspunkt. Det samme kan du gjøre med oppgaver hvis du ønsker at studentene skal samarbeide åpent.

Hvis du foretrekker en mer privat form, kan du be studentene dine om å forkere pensumet, leksjon for leksjon, til sine egne GitHub-repoer som private repoer, og gi deg tilgang. Da kan de fullføre quiz og oppgaver privat og sende dem til deg via issues på ditt klasseromsrepo.

Det finnes mange måter å få dette til å fungere i et nettbasert klasserom. Gi oss gjerne beskjed om hva som fungerer best for deg!
