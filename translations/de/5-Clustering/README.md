# Clustering-Modelle für maschinelles Lernen

Clustering ist eine Aufgabe des maschinellen Lernens, bei der versucht wird, Objekte, die einander ähneln, zu finden und diese in Gruppen zu bündeln, die Cluster genannt werden. Was das Clustering von anderen Ansätzen im maschinellen Lernen unterscheidet, ist, dass die Vorgänge automatisch ablaufen; tatsächlich kann man sagen, dass es das genaue Gegenteil von überwachten Lernen ist.

## Regionales Thema: Clustering-Modelle für den Musikgeschmack eines nigerianischen Publikums 🎧

Das vielfältige Publikum Nigerias hat unterschiedliche musikalische Vorlieben. Anhand von Daten, die von Spotify gesammelt wurden (inspiriert durch [diesen Artikel](https://towardsdatascience.com/country-wise-visual-analysis-of-music-taste-using-spotify-api-seaborn-in-python-77f5b749b421), werfen wir einen Blick auf einige in Nigeria beliebte Musik. Dieser Datensatz enthält Informationen über den 'Danceability'-Wert, 'Acousticness', Lautstärke, 'Speechiness', Popularität und Energie verschiedener Songs. Es wird interessant sein, Muster in diesen Daten zu entdecken!

In dieser Lektionenreihe entdecken Sie neue Wege, Daten mithilfe von Clustering-Techniken zu analysieren. Clustering ist besonders nützlich, wenn Ihr Datensatz keine Labels hat. Falls er Labels hat, könnten Klassifikationstechniken, wie Sie sie in vorherigen Lektionen gelernt haben, nützlicher sein. Aber in Fällen, in denen Sie unbeschriftete Daten gruppieren möchten, ist Clustering eine großartige Methode, um Muster zu erkennen.

> Es gibt nützliche Low-Code-Tools, die Ihnen helfen können, den Umgang mit Clustering-Modellen zu erlernen. Probieren Sie [Azure ML für diese Aufgabe](https://docs.microsoft.com/learn/modules/create-clustering-model-azure-machine-learning-designer/?WT.mc_id=academic-77952-leestott)
