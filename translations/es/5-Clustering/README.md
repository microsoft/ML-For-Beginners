# Modelos de agrupamiento para aprendizaje automático

El agrupamiento es una tarea de aprendizaje automático donde se busca encontrar objetos que se parezcan entre sí y agruparlos en grupos llamados clústeres. Lo que diferencia al agrupamiento de otros enfoques en aprendizaje automático es que las cosas suceden automáticamente, de hecho, es justo decir que es lo opuesto al aprendizaje supervisado.

## Tema regional: modelos de agrupamiento para el gusto musical de una audiencia nigeriana 🎧

La audiencia diversa de Nigeria tiene gustos musicales diversos. Usando datos extraídos de Spotify (inspirados en [este artículo](https://towardsdatascience.com/country-wise-visual-analysis-of-music-taste-using-spotify-api-seaborn-in-python-77f5b749b421), veamos algo de música popular en Nigeria. Este conjunto de datos incluye información sobre la puntuación de 'bailabilidad', 'acústicidad', volumen, 'verbalidad', popularidad y energía de varias canciones. ¡Será interesante descubrir patrones en estos datos!

En esta serie de lecciones, descubrirás nuevas formas de analizar datos usando técnicas de agrupamiento. El agrupamiento es especialmente útil cuando tu conjunto de datos carece de etiquetas. Si tiene etiquetas, entonces las técnicas de clasificación como las que aprendiste en lecciones anteriores pueden ser más útiles. Pero en casos donde buscas agrupar datos sin etiquetar, el agrupamiento es una excelente manera de descubrir patrones.
