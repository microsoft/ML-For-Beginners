## 教育者向け

このカリキュラムを教室で使いたいですか？どうぞお気軽にご利用ください！

実際、GitHub Classroom を使えば GitHub 自体の中でも利用することができます。

そのためには、このリポジトリをフォークしてください。各レッスンごとにリポジトリを作成する必要があるため、各フォルダーを別々のリポジトリに抽出する必要があります。そうすれば、[GitHub Classroom](https://classroom.github.com/classrooms) が各レッスンを個別に取り扱えるようになります。 

これらの[完全な手順](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/)で教室の設定方法のイメージがつかめるでしょう。

## リポジトリをそのまま使用する場合

GitHub Classroom を使わずに現在のままでこのリポジトリを使いたい場合も可能です。その場合は、どのレッスンを生徒が一緒に進めるかを伝える必要があります。

オンライン形式（Zoom、Teams、その他）では、クイズのためにブレイクアウトルームを作成し、生徒が学習の準備ができるようメンターが支援することが考えられます。その後、生徒にクイズを受けてもらい、決められた時間に「issue」として回答を提出させます。課題についても、生徒同士が公開の場で協力して作業する場合は同様にできます。

よりプライベートな形式を望む場合は、生徒にレッスンごとにカリキュラムをフォークし、各自のGitHubリポジトリでプライベートリポジトリとして管理し、あなたにアクセス権を付与させてください。そうすれば、生徒はクイズや課題をプライベートに完了し、あなたの教室リポジトリのissueを通じて提出できます。

オンライン教室形式でこれを実現する方法は多岐にわたります。あなたにとって最適な方法をぜひ教えてください！
