## Para sa mga Guro

Gusto mo bang gamitin ang kurikulum na ito sa iyong silid-aralan? Malaya kang gamitin ito!

Sa katunayan, maaari mo itong gamitin mismo sa loob ng GitHub gamit ang GitHub Classroom.

Upang magawa iyon, i-fork ang repo na ito. Kailangan mong gumawa ng isang repo para sa bawat aralin, kaya kailangan mong ihiwalay ang bawat folder sa isang hiwalay na repo. Sa ganitong paraan, maaaring kunin ng [GitHub Classroom](https://classroom.github.com/classrooms) ang bawat aralin nang hiwalay.

Ang mga [kumpletong tagubilin](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) na ito ay magbibigay sa iyo ng ideya kung paano i-set up ang iyong silid-aralan.

## Paggamit sa repo ng kasalukuyang anyo

Kung nais mong gamitin ang repo na ito sa kasalukuyang anyo nito, nang hindi gumagamit ng GitHub Classroom, maaari rin itong gawin. Kailangan mong ipaalam sa iyong mga estudyante kung aling aralin ang pag-aaralan ninyo nang sama-sama.

Sa isang online na format (Zoom, Teams, o iba pa) maaaring gumawa ka ng mga breakout rooms para sa mga pagsusulit, at gabayan ang mga estudyante upang matulungan silang maging handa para sa pag-aaral. Pagkatapos ay imbitahan ang mga estudyante na kuhanin ang mga pagsusulit at isumite ang kanilang mga sagot bilang mga 'isyu' sa takdang oras. Maaari mo ring gawin ito sa mga takdang-aralin, kung gusto mong magtrabaho ang mga estudyante nang sama-sama nang bukas.

Kung mas gusto mo ang isang mas pribadong format, hilingin sa iyong mga estudyante na i-fork ang kurikulum, aralin bawat aralin, patungo sa kanilang sariling mga pribadong GitHub repo, at bigyan ka ng access. Pagkatapos, maaari nilang tapusin ang mga pagsusulit at takdang-aralin nang pribado at isumite ito sa iyo sa pamamagitan ng mga isyu sa iyong classroom repo.

Maraming paraan upang maging maayos ito sa isang online na silid-aralan. Ipaalam mo sa amin kung ano ang pinakamainam para sa iyo!
