# Machine Learning para sa mga Nagsisimula - Isang Kurikulum

> 🌍 Maglakbay sa buong mundo habang tinutuklasan natin ang Machine Learning sa pamamagitan ng mga kultura sa daigdig 🌍

Ang mga Cloud Advocates sa Microsoft ay nagagalak na mag-alok ng 12-linggong, 26-lesson na kurikulum tungkol sa **Machine Learning**. Sa kurikulums na ito, matututuhan mo ang tinatawag na **classic machine learning**, gamit ang pangunahing Scikit-learn bilang library at iwas sa deep learning, na sakop sa aming [AI for Beginners' curriculum](https://aka.ms/ai4beginners). Isabay ang mga leksyon na ito sa aming ['Data Science for Beginners' curriculum](https://aka.ms/ds4beginners)!

Maglakbay kasama namin sa buong mundo habang inilalapat natin ang mga klasikong teknik na ito sa data mula sa maraming bahagi ng mundo. Ang bawat aralin ay may pre- at post-lesson quizzes, mga isinulat na tagubilin para matapos ang aralin, solusyon, takdang-aralin, at iba pa. Ang aming pedagohiya na nakatuon sa proyekto ay nagpapahintulot sa'yo na matuto habang gumagawa, isang subok na paraan para maka-"stick" ang mga bagong kasanayan.

## Pedagohiya

Pinili namin ang dalawang prinsipyo ng pagtuturo habang ginagawa ang kurikulums na ito: siguraduhing ito ay hands-on **project-based** at may kasamang **madalas na mga pagsusulit**. Bukod dito, ang kurikulums na ito ay may karaniwang **tema** upang magkaroon ng pagkakaisa.

Sa pagsigurong ang nilalaman ay naka-align sa mga proyekto, nagiging mas nakakaengganyo ang proseso para sa mga estudyante at nadadagdagan ang pagkatanda sa mga konsepto. Bukod pa rito, ang mababang-taya na pagsusulit bago ang klase ay nagseset ng intensyon ng estudyante para matuto ng isang paksa, samantalang ang pangalawang pagsusulit pagkatapos ng klase ay nagsisiguro ng dagdag na retention. Dinisenyo ang kurikulums na ito upang maging flexible at masaya at maaaring kunin nang buo o bahagi. Ang mga proyekto ay nagsisimula sa maliit at unti-unting lumalalim sa katapusan ng 12-linggong siklo. Kasama rin sa kurikulums ito ang isang postscript sa mga tunay na aplikasyon ng ML, na maaaring gamitin bilang extra credit o batayan ng diskusyon.

> Hanapin ang aming [Code of Conduct](CODE_OF_CONDUCT.md), [Contributing](CONTRIBUTING.md), [Translations](..), at [Troubleshooting](TROUBLESHOOTING.md) na mga patnubay. Malugod naming tinatanggap ang iyong makabuluhang feedback!

> **Tungkol sa mga wika**: Ang mga aralin ay pangunahing nakasulat sa Python, ngunit marami rin ang available sa R. Para matapos ang isang aralin sa R, pumunta sa `/solution` na folder at hanapin ang mga aralin sa R. Mayroon silang .rmd na extension na kumakatawan sa isang **R Markdown** file na simpleng maipaliwanag bilang isang pagsasama ng `code chunks` (ng R o ibang mga wika) at isang `YAML header` (na gumagabay kung paano i-format ang mga output tulad ng PDF) sa isang `Markdown document`. Kaya, nagsisilbi itong exemplar na framework para sa pagsusulat ng mga dokumento sa data science dahil pinapayagan kang pagsamahin ang iyong code, ang output nito, at ang iyong mga ideya sa pagsusulat gamit ang Markdown. Bukod pa rito, ang mga dokumento ng R Markdown ay maaaring ma-render sa output formats tulad ng PDF, HTML, o Word.

> **Tungkol sa mga pagsusulit**: Lahat ng mga pagsusulit ay nasa [Quiz App folder](../../quiz-app), para sa kabuuang 52 na pagsusulit na may tig-3 tanong bawat isa. Nakalink sila mula sa loob ng mga aralin ngunit ang quiz app ay maaaring patakbuhin nang lokal; sundin ang mga tagubilin sa `quiz-app` na folder para i-host nang lokal o i-deploy sa Azure.

## Pagkuha ng Tulong

Kung ikaw ay maiipit o may mga katanungan habang nag-aaral ng Machine Learning o gumagawa ng mga AI na aplikasyon, huwag mag-alala — mayroong tulong na magagamit.

Maaari kang sumali sa mga talakayan kasama ang ibang mga nag-aaral at mga developer, magtanong, at ibahagi ang iyong mga ideya sa komunidad.

- Sumali sa komunidad upang magtanong at matuto kasama ang iba
- Talakayin ang mga konsepto ng Machine Learning at mga ideya sa proyekto
- Kumunsulta sa mga bihasang developer

Ang isang sumusuportang komunidad ay isang mahusay na paraan upang lumago ang iyong mga kasanayan at mas mabilis na maresolba ang mga problema.

[Microsoft Foundry Discord Community](https://discord.gg/nTYy5BXMWG)

Kung makatagpo ka ng mga bug, error, o mayroong mga mungkahi para sa pagpapabuti, maaari ka ring magbukas ng **Isyu** sa repository na ito upang i-report ang problema.

Para sa feedback sa produkto o upang maghanap sa mga umiiral na post ng komunidad, bisitahin ang Developer Forum:

[![Microsoft Foundry Developer Forum](https://img.shields.io/badge/GitHub-Microsoft_Foundry_Developer_Forum-blue?style=for-the-badge&logo=github&color=000000&logoColor=fff)](https://aka.ms/foundry/forum)

## Karagdagang Mga Tip sa Pag-aaral

- Balikan ang mga notebook pagkatapos ng bawat aralin para sa mas mahusay na pag-unawa.
- Magpraktis sa pag-implementa ng mga algorithm mag-isa.
- Tuklasin ang mga totoong dataset gamit ang mga natutunang konsepto.
