## បរិយាកាសសមាសភាពសម្រាប់​ការ​អភិវឌ្ឍន៍ ML របស់អ្នក

អ្នកនឹងប្រើ **notebooks** ក្នុងការអភិវឌ្ឍកូដ Python របស់អ្នក និងបង្កើតគំរូមាស៊ីនសិក្សា។ ប្រភេទឯកសារនេះគឺជាឧបករណ៍ធម្មតាសម្រាប់អ្នកវិទ្យាសាស្ត្រទិន្នន័យ ហើយពួកវាអាចកំណត់ដោយសញ្ញាដូចជា `.ipynb`។

Notebooks គឺជាបរិយាកាសអន្តរក្រិតដែលអនុញ្ញាតឱ្យអ្នកអភិវឌ្ឍទាំងកូដ និងបន្ថែមកំណត់ចំណាំ និងសរសេរឯកសារនាំក្រៅពីកូដ ដែលមានប្រយោជន៍សម្រាប់គម្រោងស្រាវជ្រាវឬជំរុញការប្រមូលតេស្ត។

[![ML សម្រាប់អ្នកថ្មី - រៀបចំ Jupyter Notebooks ដើម្បីចាប់ផ្តើមបង្កើតគំរូរែក្រេស្ស្យុង](https://img.youtube.com/vi/7E-jC8FLA2E/0.jpg)](https://youtu.be/7E-jC8FLA2E "ML សម្រាប់អ្នកថ្មី - រៀបចំ Jupyter Notebooks ដើម្បីចាប់ផ្តើមបង្កើតគំរូរែក្រេស្ស្យុង")

> 🎥 ចុចរូបភាពខាងលើសម្រាប់វីដេអូខ្លីបង្ហាញរបៀបធ្វើកិច្ចការ។

### កិច្ចការ - ប្រើប្រាស់ notebook មួយ

ក្នុងថតនេះ អ្នកនឹងឃើញឯកសារ _notebook.ipynb_។

1. បើក _notebook.ipynb_ ក្នុង Visual Studio Code។

   ម៉ាស៊ីនបម្រើ Jupyter នឹងចាប់ផ្តើមជាមួយ Python 3+។ អ្នក​នឹង​ឃើញ​ផ្នែក​នៃ notebook ដែលអាចជា `run` ដែលជាផ្នែកកូដ។ អ្នកអាចរត់ប្លុកកូដ ដោយជ្រើសរើសរូបសញ្ញាដែលមើលទៅដូចជា​ប៊ូតុង​ចាក់​សំឡេង។

1. ជ្រើសរើសរូបសញ្ញា `md` ហើយបន្ថែមមួយចំនួននៃ markdown និងអត្ថបទខាងក្រោមនេះ **# សូមស្វាគមន៍មកកាន់ notebook របស់អ្នក**។

   បន្ទាប់មក បន្ថែមកូដ Python មួយចំនួន។

1. សរសេរ **print('hello notebook')** នៅក្នុងប្លុកកូដ។
1. ជ្រើសរើសរូបសញ្ញាអ្នមគោលបញ្ជាដើម្បីរត់កូដ។

   អ្នកគួរតែឃើញសេចក្ដីបោះពុម្ពនេះ៖

    ```output
    hello notebook
    ```

## កំពុងដំណើរការជាមួយ Scikit-learn

ឥឡូវនេះ Python បានរៀបចំរួចនៅក្នុងបរិយាកាសផ្ទាល់ខ្លួនរបស់អ្នក ហើយអ្នកបានស្គាល់ Jupyter Notebooks ដោយស្រេចហើយ បណ្តាញតាមភាសា Scikit-learn (អានថា `sci` ដូចជា `science`)។ Scikit-learn ផ្តល់នូវ [API ធំទូលាយ](https://scikit-learn.org/stable/modules/classes.html#api-ref) ដើម្បីជួយអ្នកអនុវត្តកិច្ចការសិក្សាម៉ាស៊ីន។

អោយតាម [គេហទំព័ររបស់ពួកគេ](https://scikit-learn.org/stable/getting_started.html) "Scikit-learn គឺជាបណ្ណាល័យរំពឹងមួយសម្រាប់សិក្សាម៉ាស៊ីនដែលគាំទ្រការសិក្សាប្រភេទបង្រួបបង្រួម និងមិនប្រភេទបង្រួបបង្រួម។ វាក៏ផ្តល់ឧបករណ៍ជាច្រើនសម្រាប់ការចងក្រងគំរូ ការប្រព្រឹត្តមួកទិន្នន័យជាមុន ការជ្រើសរើសគំរូ និងការវាយតម្លៃ និងឧបករណ៍ផ្សេងទៀត។"

ក្នុងវគ្គនេះ អ្នកនឹងប្រើ Scikit-learn និងឧបករណ៌ផ្សេងទៀតក្នុងការបង្កើតគំរូសិក្សាម៉ាស៊ីន ដើម្បីអនុវត្តកិច្ចការដែលយើងហៅថា 'សិក្សាម៉ាស៊ីនប្រពៃណី'។ យើងបានជៀសវាងបណ្ដាញប្រសាទ និងការសិក្សាដោយជម្រៅ ប៉ុន្ដែដោយប្រយោគថា វា​ត្រូវ​បានគ្របដណ្តប់ល្អក្នុងមេរៀន​ជួយ​ដៅផ្ទាល់ខ្លួន​ 'AI សម្រាប់អ្នកថ្មី' ដែលនឹងមកដល់។

Scikit-learn ធ្វើឱ្យវាងាយស្រួលក្នុងការបង្កើតគំរូ និងវាយតម្លៃសម្រាប់ប្រើប្រាស់។ វាផ្តោតខ្លាំងលើទិន្នន័យលេខាទាំងឡាយ និងមានឈុតទិន្នន័យរៀបចំរួចសម្រាប់ប្រើប្រាស់ជាឧបករណ៍រៀន។ វាក៏មានគំរូដំណាក់កាលដែលបានបង្កើតរួចសម្រាប់សិស្សរៀន។ មកយើងស្វែងយល់ក្រុមហ៊ុននៃការផ្ទុកទិន្នន័យរួចហើយ និងប្រើកាតាអាមេតិករមួយក្នុង Scikit-learn ដើម្បីបង្កើតគំរូ ML ជាលើកដំបូង ដោយប្រើទិន្នន័យមូលដ្ឋានមួយ។

## កិច្ចការ - notebook Scikit-learn ដំបូងរបស់អ្នក

> មេរៀននេះបានរងចាំពី [គំរូរែក្រេស្ស្យុងតាមបន្ទាត់](https://scikit-learn.org/stable/auto_examples/linear_model/plot_ols.html#sphx-glr-auto-examples-linear-model-plot-ols-py) នៅលើគេហទំព័រ Scikit-learn។


[![ML សម្រាប់អ្នកថ្មី - គម្រោងរែក្រេស្ស្យុងតាមបន្ទាត់ដំបូងរបស់អ្នកនៅក្នុង Python](https://img.youtube.com/vi/2xkXL5EUpS0/0.jpg)](https://youtu.be/2xkXL5EUpS0 "ML សម្រាប់អ្នកថ្មី - គម្រោងរែក្រេស្ស្យុងតាមបន្ទាត់ដំបូងរបស់អ្នកនៅក្នុង Python")

> 🎥 ចុចរូបភាពខាងលើសម្រាប់វីដេអូខ្លីបង្ហាញរបៀបធ្វើកិច្ចការ។

នៅក្នុងឯកសារ _notebook.ipynb_ ដែលជាតំណភ្ជាប់មកមេរៀននេះ សូមសម្អាតក្រឡាចេញពីគ្រប់កោសិការដោយចុចរូបតំណាង 'ធុងសំរាម'។

នៅក្នុងផ្នែកនេះ អ្នកនឹងធ្វើការ​ជាមួយ​ឈុតទិន្នន័យ​តូចមួយ​អំពី​ជំងឺទឹកនោមផ្អែម ដែលបញ្ចូលក្នុង Scikit-learn សម្រាប់​គោលបំណងរៀន។ សូមស្រមៃថា អ្នកចង់សាកល្បងវិធីសាស្ត្រព្យាបាលសម្រាប់អ្នកជំងឺជំងឺទឹកនោមផ្អែម។ គំរូសិក្សាម៉ាស៊ីនអាចជួយអ្នកកំណត់ថា អ្នកជំងឺតើនឹងឆ្លើយតបលើការព្យាបាលល្អប្រសើរណា ដោយផ្អែកលើការរួមបញ្ចូលអថេរជាច្រើន។ គំរូរែក្រេស្ស្យុងមូលដ្ឋានមួយបើមានការត្រួតពិនិត្យ ក៏អាចបង្ហាញព័ត៌មានអំពីអថេរដែលអាចជួយអ្នករៀបចំសាកល្បងគ្លីនិកក្នុងគំនិតទ្រឹស្តីបាន។

✅ មានវិធីសាស្ត្ររែក្រេស្ស្យុងជាច្រើនប្រភេទ ហើយការជ្រើសរើសរបស់អ្នកអាស្រ័យលើចម្លើយដែលអ្នកចង់ស្វែងរក។ ប្រសិនបើអ្នកចង់គណនាកម្ពស់ដែលវាស់បានសម្រាប់មនុស្សម្នាក់នៅអាយុជាក់លាក់ទម្រង់ អ្នកនឹងប្រើរែក្រេស្ស្យុងតាមបន្ទាត់ ព្រោះអ្នកកំពុងស្វែងរក **ចំនួនលេខ**។ ប្រសិនបើអ្នកចង់ស្វែងរកថាតើប្រភេទម្ហូបណាមួយគួរត្រូវបានចាត់ទុកថា គឺថាសាកលែង ឬមិនមែន ទោះបីជាអ្នកកំពុងស្វែងរក **កំណត់ប្រភេទ** អ្នកនឹងប្រើរែក្រេស្ស្យុងឡូជីសទិក។ អ្នកនឹងរៀនបន្ថែមអំពីរែក្រេស្ស្យុងឡូជីសទិកនៅពេលក្រោយ។ សូមគិតពីសំណួរមួយចំនួនដែលអ្នកអាចស្នើរពីទិន្នន័យ ហើយវិធីសាស្ត្រមួយណាដែលសមស្របជាងគេ។

ចូរចាប់ផ្តើមអនុវត្តកិច្ចការនេះ។

### នាំចូលបណ្ណាល័យ

សម្រាប់កិច្ចការ​នេះ យើងនឹងនាំចូលបណ្ណាល័យខ្លះ៖

- **matplotlib**។ វាជាឧបករណ៍ [គូរជាមួយក្រាផ](https://matplotlib.org/) មួយដែលមានប្រយោជន៍ ហើយយើងនឹងប្រើវាទៅបង្កើតក្រាផបន្ទាត់មួយ។
- **numpy**។ [numpy](https://numpy.org/doc/stable/user/whatisnumpy.html) គឺជាបណ្ណាល័យមានប្រយោជន៍សម្រាប់ដោះស្រាយទិន្នន័យលេខក្នុង Python។
- **sklearn**។ នេះគឺជាបណ្ណាល័យ [Scikit-learn](https://scikit-learn.org/stable/user_guide.html)។

នាំចូលបណ្ណាល័យខ្លះដើម្បីជួយសម្រេចកិច្ចការ។

1. បន្ថែមការនាំចូលដោយសរសេរកូដដូចខាងក្រោម៖

   ```python
   import matplotlib.pyplot as plt
   import numpy as np
   from sklearn import datasets, linear_model, model_selection
   ```

   ខាងលើ អ្នកកំពុង​នាំចូល `matplotlib`, `numpy` ហើយនាំចូល `datasets`, `linear_model` និង `model_selection` ពី `sklearn`។ `model_selection` ត្រូវបានប្រើសម្រាប់បំបែកទិន្នន័យទៅកាន់ក្រុមហ៊ុនបណ្តុះបណ្តាល និងក្រុមសាកល្បង។

### ឈុតទិន្នន័យជំងឺទឹកនោមផ្អែម

ឈុតទិន្នន័យ [ជំងឺទឹកនោមផ្អែម](https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset) ដែលបញ្ចូលក្នុងគឺរួមមាន ៤៤២ លរិះទិន្នន័យអំពីជំងឺទឹកនោមផ្អែម មានអថេរកំណត់ចំនួន ១០ ខ្លះៗរួមមាន៖

- អាយុ៖ អាយុវ័យក្នុងឆ្នាំ
- BMI: សន្ទស្សន៍មាត្រប៉ារ៉ាម៉ែត្រ גוף
- BP: សម្ពាធឈាមជាមធ្យម
- S1 TC: កោសិកា-T (ប្រភេទកោសិកាឈាមស)

✅ ឈុតទិន្នន័យនេះមានមុខងារ 'ភេទ' ជាអថេរដែលមានសារៈសំខាន់សម្រាប់ការស្រាវជ្រាវជុំវិញជំងឺទឹកនោមផ្អែម។ ឈុតទិន្នន័យវេជ្ជសាស្ត្រជាច្រើនរួមបញ្ចូលកំណត់ចំណែកឌីណា(binary classification) បែបនេះ។ សូមគិតពីរបៀបដាក់ចំណាត់ថ្នាក់ដូចនេះដែលបូកស្មើការច្រានចោលក្រុមប្រជាជនខ្លះពីការព្យាបាល។

ឥឡូវនេះ បើកទិន្នន័យ X និង y។

> 🎓 ចេះថា នេះគឺជាការសិក្សាប្រភេទត្រូវបានគ្រប់គ្រង (supervised learning) ហើយយើងត្រូវការគោលដៅមានឈ្មោះ 'y'។

នៅក្នុងកោសិកាថ្មីមួយ ប្រើកូដក្នុងការផ្ទុកឈុតទិន្នន័យជំងឺទឹកនោមផ្អែមដោយហៅ `load_diabetes()`។ វាយបញ្ចូល `return_X_y=True` បញ្ចាក់ថា `X` នឹងជាម៉ាត្រិចទិន្នន័យ ហើយ `y` នឹងជាគោលដៅរែក្រេស្ស្យុង។

1. បន្ថែមពាក្យបោះពុម្ពដើម្បីបង្ហាញរាងរែកនៃម៉ាត្រិចទិន្នន័យ និងធាតុដំបូងសម្រាប់វា៖

    ```python
    X, y = datasets.load_diabetes(return_X_y=True)
    print(X.shape)
    print(X[0])
    ```

    អ្វីដែលអ្នកទទួលបានជាទម្លាប់ គឺជា tuple។ អ្វីដែលអ្នកកំពុងធ្វើ គឺចាត់តម្លៃពីរដំបូងរបស់ tuple ទៅកាន់ `X` និង `y` តាមលំដាប់។ សូមស្វែងយល់បន្ថែម [អំពី tuples](https://wikipedia.org/wiki/Tuple)។

    អ្នកអាចមើលឃើញទិន្នន័យនេះមាន ៤៤២ ឥតសូមដែលត្រូវបានរៀបចំក្នុងអារ៉េដែលមាន ១០ ធាតុ។

    ```text
    (442, 10)
    [ 0.03807591  0.05068012  0.06169621  0.02187235 -0.0442235  -0.03482076
    -0.04340085 -0.00259226  0.01990842 -0.01764613]
    ```

    ✅ សូមគិតពីទំនាក់ទំនងរវាងទិន្នន័យ និងគោលដៅរែក្រេស្ស្យុង។ រែក្រេស្ស្យុងតាមបន្ទាត់ទាយទាក់ទងរវាងលក្ខណៈ X និងអថេរគោលដៅ y។ តើអ្នកអាចស្វែងរក [គោលដៅ](https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset) សម្រាប់ឈុតទិន្នន័យជំងឺទឹកនោមផ្អែមនៅក្នុងឯកសារពិពណ៌នាត្រូវបានបង្ហាញ? តើឈុតទិន្នន័យនេះបង្ហាញអ្វីដោយមានគោលដៅនោះ?

2. បន្ទាប់មក ជ្រើសរើសផ្នែកមួយនៃទិន្នន័យនេះដើម្បីបង្ហាញដោយជ្រើសរើសជួរឈរ​ទី 3 នៃទិន្នន័យ។ អ្នកអាចធ្វើបាននេះដោយប្រើកម្មវិធី `:` ដើម្បីជ្រើសរើសជួរក្នុងទាំងអស់ ហើយបន្ទាប់មកជ្រើសរើសជួរឈរ​ទី 3 ដោយប្រើសន្ទស្សន៍ (2)។ អ្នកក៏អាចបម្លែងទិន្នន័យទៅជា​អារេ 2D ដូចដែលត្រូវការ​សម្រាប់ការបង្ហាញប្លង់ដោយប្រើ `reshape(n_rows, n_columns)`។ ប្រសិនបើប៉ារ៉ាម៉ែត្រណាមួយមានតម្លៃ -1 អង្កត់ផ្ចិតដែលផ្ទ្លាប់នឹងត្រូវគណនាដោយស្វ័យប្រវត្តិ។

   ```python
   X = X[:, 2]
   X = X.reshape((-1,1))
   ```

   ✅ នៅពេលណាមួយ សូមបោះពុម្ពទិន្នន័យរបស់អ្នកដើម្បីពិនិត្យមើលរាងរបស់វា។

3. ឥឡូវនេះដែលអ្នកមានទិន្នន័យសម្រាប់បង្ហាញប្លង់ អ្នកអាចមើលថាម៉ាសុីនមួយអាចជួយកំណត់ការបំបែកចែកចាយមានហេតុផលរវាងលេខនៅក្នុងទិន្នន័យនេះដែរឬទេ។ ដើម្បីធ្វើនេះ អ្នកត្រូវបំបែកទិន្នន័យទាំង X និងគោលដៅ y ទៅជាកំណត់បែបសាកល្បង និងបណ្ដុះបណ្ដាល។ Scikit-learn មានវិធីងាយសំរាប់ធ្វើការបំបែកទិន្នន័យរបស់អ្នកតាមចំណុចណាមួយ។

   ```python
   X_train, X_test, y_train, y_test = model_selection.train_test_split(X, y, test_size=0.33)
   ```

4. ឥឡូវនេះអ្នកបានរៀបចំរួចរាល់សម្រាប់បណ្ដុះបណ្ដាលម៉ូដែលរបស់អ្នក! ផ្ទុកម៉ូដែលផលប៉ះពាល់បន្ទាត់ស្រប និងបណ្ដុះបណ្ដាលវាជាមួយសំណុំទិន្នន័យបណ្ដុះបណ្ដាល X និង y ដោយប្រើ `model.fit()`:

    ```python
    model = linear_model.LinearRegression()
    model.fit(X_train, y_train)
    ```

    ✅ `model.fit()` គឺជាអង្គភាពដែលអ្នកនឹងឃើញនៅក្នុងបណ្ណាល័យ ML ដូចជា TensorFlow

5. បន្ទាប់មក បង្កើត ការពូងពេលដោយប្រើទិន្នន័យសាកល្បង ដោយប្រើអង្គភាព `predict()`។ វានឹងត្រូវបានប្រើដើម្បីគូរបន្ទាត់រវាងក្រុមទិន្នន័យ។

    ```python
    y_pred = model.predict(X_test)
    ```

6. ឥឡូវនេះពេលវេលាសម្រាប់បង្ហាញទិន្នន័យក្នុងប្លង់។ Matplotlib គឺពិធីការដ៏មានប្រយោជន៍សម្រាប់ការងារនេះ។ បង្កើតscatterplot របស់ទិន្នន័យ X និង y សាកល្បងទាំងអស់ ហើយប្រើការពូងពេល ដើម្បីគូរបន្ទាត់នៅចំណុចសមស្របបំផុត ក្នុងក្រុមទិន្នន័យនៃម៉ូដែល។

    ```python
    plt.scatter(X_test, y_test,  color='black')
    plt.plot(X_test, y_pred, color='blue', linewidth=3)
    plt.xlabel('Scaled BMIs')
    plt.ylabel('Disease Progression')
    plt.title('A Graph Plot Showing Diabetes Progression Against BMI')
    plt.show()
    ```

   ![a scatterplot showing datapoints around diabetes](../../../../translated_images/km/scatterplot.ad8b356bcbb33be6.webp)

   ✅ សូមគិតបន្តិចពីអ្វីដែលកំពុងកើតឡើងនៅទីនេះ។ បន្ទាត់ស្របមួយកំពុងរត់កាត់តំបន់ចំណុចតូចៗជាច្រើននៃទិន្នន័យ ប៉ុន្តែម្យ៉ាងវិញ តើវាកំពុងធ្វើអ្វី? តើអ្នកអាចមើលឃើញថាតើអ្នកគួរតែប្រើបន្ទាត់នេះដើម្បីព្យាករណ៍បានពីកន្លែងដែលចំណុចទិន្នន័យថ្មី មិនដែលឃើញមុននោះ គួរតែស្ថិតក្នុងទំនាក់ទំនងជាមួយអ័ក្ស y នៃប្លង់? សូមព្យាយាមពណ៌នាឲ្យទាន់ចិត្តពីការប្រើប្រាស់លទ្ធប្រយោជន៍នៃម៉ូដែលនេះ។

សូមអបអរសាទរ លោកអ្នកបានកសាងម៉ូដែលរេសហ្ស៊ីស្យុងបន្ទាត់ស្របដំបូងរបស់អ្នក ក៏បានបង្កើតការព្យាករណ៍ជាមួយវា ហើយបានបង្ហាញវានៅក្នុងប្លង់!
