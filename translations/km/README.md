# ការសិក្សាគ្រឹះសម្រាប់អ្នកចាប់ផ្ដើម - មេរៀនមូលដ្ឋាន

ដើរផ្លូវជាមួយយើងជុំវិញពិភពលោក ពេលយើងអនុវត្តបច្ចេកទេសបុរាណទាំងនេះទៅលើទិន្នន័យពីតំបន់ជាច្រើន។ មេរៀននិមួយៗរួមមានតេស្តមុន និងបន្ទាប់មេរៀន, ចំណាំសរសេរដើម្បីបញ្ចប់មេរៀន, ដំណោះស្រាយ, ការចូលរួមតែង, និងផ្សេងៗទៀត។ វិធីសាស្រ្តការបង្រៀនផ្អែកលើគម្រោងអនុញ្ញាតឲ្យអ្នករៀនខណៈតែមួយកំពុងបង្កើតអ្វីមួយ ដែលជាវិធីដ៏មានប្រសិទ្ធភាពសម្រាប់ជំនាញថ្មីរឹតតែចងចាំបាន។

អ្នកអាចចូលរួមពិភាក្សាជាមួយអ្នករៀន និងអ្នកអភិវឌ្ឍជាម្នាក់ៗ សួរប្រសិនបើមានចម្ងល់ និងចែករំលែកគំនិតជាមួយសហគមន៍។

- ចូលក្នុងសហគមន៍ដើម្បីសួរចម្លើយ និងរៀនជាមួយមនុស្សផ្សេងទៀត
- ពិភាក្សាអំពីគំនិតនៃការរៀនម៉ាស៊ីន និងគម្រោង
- ទទួលបានការណែនាំពីអ្នកអភិវឌ្ឍមានបទពិសោធន៍

សហគមន៍គាំទ្រជាជម្រើសល្អសម្រាប់ពង្រីកជំនាញនិងដោះស្រាយបញ្ហា យ៉ាងរហ័ស។

[Microsoft Foundry Discord Community](https://discord.gg/nTYy5BXMWG)

ប្រសិនបើអ្នកជួបបញ្ហាកំហុស ឬមានស្នើសុំកែលម្អ អ្នកអាចបើកបញ្ហា **Issue** នៅក្នុងឃ្លាំងនេះ ដើម្បីរាយការណ៍បញ្ហា។

សម្រាប់មតិយោបល់ផលិតផល ឬស្វែងរកសារសហគមន៍មានស្រាប់ សូមទៅកាន់វិទ្យាស្ថានអ្នកអភិវឌ្ឍ៖

[![Microsoft Foundry Developer Forum](https://img.shields.io/badge/GitHub-Microsoft_Foundry_Developer_Forum-blue?style=for-the-badge&logo=github&color=000000&logoColor=fff)](https://aka.ms/foundry/forum)

## កំប្លែងបន្ថែមសម្រាប់ការរៀន

- ពិនិត្យមើលសៀវភៅកំណត់ត្រាជាបន្តបន្ទាប់តាមមេរៀនសម្រាប់ការយល់ដឹងល្អជាងមុន។
- ហាត់ធ្វើអនុវត្តកម្មវិធីតាមខ្លួនឯង។
- ស្វែងយល់អំពីទិន្នន័យពិតប្រាកដដោយប្រើយល់គំនិតដែលបានរៀន។
