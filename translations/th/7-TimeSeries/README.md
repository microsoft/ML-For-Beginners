# บทนำสู่การพยากรณ์ลำดับเวลา

การพยากรณ์ลำดับเวลาคืออะไร? คือการทำนายเหตุการณ์ในอนาคตโดยการวิเคราะห์แนวโน้มจากอดีต

## หัวข้อภูมิภาค: การใช้ไฟฟ้าทั่วโลก ✨

ในสองบทเรียนนี้ คุณจะได้แนะนำเกี่ยวกับการพยากรณ์ลำดับเวลา ซึ่งเป็นสาขาที่ค่อนข้างไม่ค่อยเป็นที่รู้จักนักในด้านการเรียนรู้ของเครื่อง แต่มีคุณค่าอย่างมากสำหรับอุตสาหกรรมและการใช้งานในธุรกิจ รวมถึงสาขาอื่น ๆ ในขณะที่เครือข่ายประสาทเทียมสามารถใช้เพื่อเสริมประสิทธิภาพของโมเดลเหล่านี้ เราจะศึกษาพวกมันในบริบทของการเรียนรู้ของเครื่องแบบคลาสสิกเนื่องจากโมเดลเหล่านี้ช่วยในการทำนายผลการดำเนินงานในอนาคตจากอดีต

โฟกัสในภูมิภาคของเราคือการใช้ไฟฟ้าทั่วโลก ชุดข้อมูลที่น่าสนใจในการเรียนรู้เกี่ยวกับการพยากรณ์การใช้พลังงานไฟฟ้าในอนาคตโดยพิจารณาจากรูปแบบการใช้โหลดในอดีต คุณจะเห็นว่าการพยากรณ์ประเภทนี้สามารถช่วยได้อย่างมากในสภาพแวดล้อมธุรกิจ
