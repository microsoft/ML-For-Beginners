## สำหรับครูผู้สอน

คุณต้องการใช้หลักสูตรนี้ในห้องเรียนของคุณไหม? โปรดใช้ได้ตามสะดวก!

แท้จริงแล้ว คุณสามารถใช้มันภายใน GitHub โดยใช้ GitHub Classroom ได้

ในการทำเช่นนั้น ให้โฟรก repo นี้ คุณจะต้องสร้าง repo สำหรับแต่ละบทเรียน ดังนั้นคุณจะต้องแยกแต่ละโฟลเดอร์ออกมาเป็น repo แยกต่างหาก เพื่อที่ [GitHub Classroom](https://classroom.github.com/classrooms) จะได้เลือกแต่ละบทเรียนแยกกัน

[คำแนะนำเต็มรูปแบบ](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) เหล่านี้จะช่วยให้คุณเข้าใจวิธีการตั้งค่าห้องเรียน

## การใช้ repo ตามที่เป็น

หากคุณต้องการใช้ repo นี้ตามที่มีอยู่ในขณะนี้ โดยไม่ใช้ GitHub Classroom ก็สามารถทำได้เช่นกัน คุณจะต้องสื่อสารกับนักเรียนของคุณว่าให้ทำบทเรียนไหนด้วยกัน

ในรูปแบบออนไลน์ (Zoom, Teams หรืออื่น ๆ) คุณอาจจัดห้องพักแยกสำหรับแบบทดสอบ และเป็นพี่เลี้ยงช่วยนักเรียนเตรียมพร้อมสำหรับการเรียน จากนั้นเชิญนักเรียนทำแบบทดสอบและส่งคำตอบเป็น 'issues' ในเวลาที่กำหนด คุณอาจทำแบบเดียวกันกับงานถ้าคุณต้องการให้นักเรียนทำงานร่วมกันแบบเปิด

หากคุณต้องการรูปแบบที่เป็นส่วนตัวมากขึ้น ขอให้นักเรียนโฟรกหลักสูตร บทเรียนละบทเรียน ไปยัง repo ของ GitHub ส่วนตัวของพวกเขา และให้คุณเข้าถึง จากนั้นพวกเขาสามารถทำแบบทดสอบและงานอย่างเป็นส่วนตัว และส่งให้คุณผ่าน issues บน repo ห้องเรียนของคุณ

มีหลายวิธีที่จะทำให้สิ่งนี้ได้ผลในรูปแบบห้องเรียนออนไลน์ โปรดแจ้งให้เราทราบว่าวิธีใดเหมาะกับคุณที่สุด!

## กรุณาแสดงความคิดเห็นของคุณ!

เราต้องการทำให้หลักสูตรนี้เหมาะกับคุณและนักเรียนของคุณ โปรดให้ [คำติชม](https://forms.microsoft.com/Pages/ResponsePage.aspx?id=v4j5cvGGr0GRqy180BHbR2humCsRZhxNuI79cm6n0hRUQzRVVU9VVlU5UlFLWTRLWlkyQUxORTg5WS4u) แก่เรา
