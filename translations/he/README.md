> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ML-For-Beginners.git
> cd ML-For-Beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (חלונות):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ML-For-Beginners.git
> cd ML-For-Beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> זה נותן לכם את כל מה שצריך לסיים את הקורס עם הורדה הרבה יותר מהירה.

# למידת מכונה למתחילים - תכנית לימודים

> 🌍 טיילו בעולם תוך כדי חקר למידת מכונה באמצעות תרבויות העולם 🌍

סנגורי ענן במיקרוסופט שמחים להציע תכנית לימודים בת 12 שבועות, 26 שיעורים, הכוללת את הנושא **למידת מכונה**. בתכנית זו תלמדו על מה שלפעמים נקרא **למידת מכונה קלאסית**, בעיקר באמצעות ספריית Scikit-learn ותמנעתם מלמידה עמוקה, הנלמדת בתכנית [AI למתחילים](https://aka.ms/ai4beginners) שלנו. ניתן גם לשלב שיעורים אלו עם תכנית ['מדעי הנתונים למתחילים'](https://aka.ms/ds4beginners)!

טיילו איתנו בעולם בזמן שאנו מיישמים את הטכניקות הקלאסיות הללו על נתונים מאזורים שונים בעולם. בכל שיעור יש חידונים לפני ואחרי השיעור, הוראות כתובות להשלמת השיעור, פתרון, מטלה, ועוד. הגישה המתמקדת בפרויקטים שלנו מאפשרת ללמוד תוך כדי בנייה, שיטה מוכחת ללמידת מיומנויות חדשות.

**✍️ תודה רבה למחברינו** ג'ן לופר, סטיבן האואל, פרנססקה לזזרי, טומומי אימורה, קסי ברוויו, דמיטרי סושניקוב, כריס נורינג, אנירבן מוכרג'י, אורנלה אלטוניאן, רות יאקובו ואיימי בוייד

**🎨 תודה גם למאיירים שלנו** טומומי אימורה, דסאני מדיפאלי, וג'ן לופר

**🙏 תודה מיוחדת 🙏 למחברי שגרירי הסטודנטים במיקרוסופט, לסוקרים ולתורמים לתוכן**, במיוחד לרישיט דגלי, מוחמד סאקיב חאן אינאן, רוהאן ראג', אלכסנדרו פטרסקו, אבישק ג'ייסוואל, נאוורין טבאסום, יואן סמויאלה, וסניגדה אגרוואל

**🤩 תודה נוספת לשגרירי הסטודנטים של מיקרוסופט אריק ואנג'או, ג'אסלין סונדהי, ווידושי גופטה על שיעורי R שלנו!**

# התחלה

עקבו אחרי הצעדים הבאים:
1. **צרו Fork למאגר**: לחצו על כפתור "Fork" בפינה הימנית העליונה של העמוד הזה.
2. **שכפלו את המאגר**:   `git clone https://github.com/microsoft/ML-For-Beginners.git`

> 💡 **טיפ התחלה מהירה:** רוצים להתחיל בדפדפן בלי להגדיר Python מקומית? השתמשו ב-[GitHub Codespaces](https://github.com/features/codespaces) ליצירת סביבת פיתוח בענן עבור ה-fork שלכם. פתחו את התפריט הירוק של **קוד**, בחרו ב-**Codespaces**, וצרו codespace; התקינו בכל קודספייס את התלויות שדורש כל שיעור לפי הצורך.

> [מצאו את כל המשאבים הנוספים לקורס זה באוסף Microsoft Learn שלנו](https://learn.microsoft.com/en-us/collections/qrqzamz1nn2wx3?WT.mc_id=academic-77952-bethanycheum)

> 🔧 **צריכים עזרה?** בדקו את [מדריך פתרון הבעיות](TROUBLESHOOTING.md) שלנו לפתרונות לבעיות נפוצות בהתקנה, בהגדרה ובהפעלת השיעורים.


**[סטודנטים](https://aka.ms/student-page)**, כדי להשתמש בתכנית זו, צרו fork למאגר כולו לחשבון ה-GitHub האישי שלכם ושלימו את התרגילים בעצמכם או בקבוצה:

- התחילו עם חידון לפני ההרצאה.
- קראו את ההרצאה והשלימו את הפעילויות, עצרו והרהרו בכל בדיקת ידע.
- נסו ליצור את הפרויקטים על ידי הבנת השיעורים במקום להריץ את קוד הפתרון; עם זאת, קוד זה זמין בתיקיות `/solution` בכל שיעור ממוקד פרויקט.
- עברו חידון לאחר ההרצאה.
- השלימו את האתגר.
- השלימו את המטלה.
- לאחר סיום קבוצת שיעורים, בקרו ב-[לוח הדיונים](https://github.com/microsoft/ML-For-Beginners/discussions) ו"תלמדו בקול", על ידי מילוי סולם PAT המתאים. 'PAT' הוא כלי להערכת התקדמות שאתם ממלאים להמשך הלמידה. תוכלו גם להגיב ל-PAT של אחרים כדי שנוכל ללמוד יחד.

> ללמידה נוספת, אנו ממליצים על מעקב אחרי מודולים ונתיבי למידה ב-[Microsoft Learn](https://docs.microsoft.com/en-us/users/jenlooper-2911/collections/k7o7tg1gp306q4?WT.mc_id=academic-77952-leestott).

## פדגוגיה

בחרנו שני עקרונות פדגוגיים בבניית תכנית זו: להבטיח שהיא **פרויקטית ומעשית** ושתכלול **חידונים תכופים**. בנוסף, לתכנית יש **נושא** משותף שמקנה לה אחידות.

על ידי התאמת התוכן לפרויקטים, התהליך נעשה מעניין יותר לתלמידים ודברים נזכרים טוב יותר. כמו כן, חידון בעל סיכון נמוך לפני השיעור מכוון את כוונת התלמיד ללמידת הנושא, בעוד חידון נוסף אחרי השיעור מבטיח שמירה על הידע. תכנית זו עוצבה להיות גמישה ומהנה וניתן ללמוד אותה בשלמותה או בחלקיה. הפרויקטים מתחילים קטנים והופכים למורכבים יותר לקראת סוף מחזור 12 השבועות. לתכנית יש גם סימוכין ליישומים אמיתיים של למידת מכונה, שניתן להשתמש בהם כקרדיט נוסף או כבסיס לדיון.

> מצאו את הקווים המנחים שלנו ל-[קוד ההתנהגות](CODE_OF_CONDUCT.md), [השתתפות](CONTRIBUTING.md), [תרגומים](..), ו-[פתרון בעיות](TROUBLESHOOTING.md). נשמח למשוב בונה שלכם!

> **הערה על שפות**: השיעורים כתובים בעיקר בפייתון, אך רבים זמינים גם ב-R. כדי להשלים שיעור R, גשו לתיקיית `/solution` וחפשו שיעורי R. הם כוללים סיומת .rmd המייצגת קובץ **R Markdown** שניתן להגדירו כפשטות כהטמעה של `code chunks` (של R או שפות אחרות) ו-`YAML header` (הכוונה כיצד לעצב פלטים כגון PDF) בתוך `Markdown document`. אפוא, הוא משמש כמסגרת יצירה מצוינת למדעי הנתונים כיוון שהוא מאפשר לשלב קוד, הפלט והמחשבות בכך שניתן לרשום אותן במארקדאון. בנוסף, קבצי R Markdown ניתנים להמרה לפורמטים כמו PDF, HTML או וורד.

> **הערה על חידונים**: כל החידונים נמצאים בתיקיית [Quiz App](../../quiz-app), בסך הכול 52 חידונים של שלוש שאלות כל אחד. הם מקושרים מתוך השיעורים אך ניתן להריץ את אפליקציית החידונים מקומית; עקבו אחרי ההוראות בתיקיית `quiz-app` לאירוח או פריסה מקומית לאזור הענן Azure.
