## 給教育工作者

你想在你的課堂中使用這個課程嗎？請隨意使用！

事實上，你可以直接在 GitHub 上使用它，透過 GitHub Classroom 來操作。

為此，請分叉這個倉庫。你需要為每一課建立一個倉庫，所以你需要將每個資料夾拆分成獨立的倉庫。這樣， [GitHub Classroom](https://classroom.github.com/classrooms) 才能分別捕捉每一課。 

這些 [完整說明](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) 會讓你了解如何設置你的課堂。

## 直接使用此倉庫

如果你想直接使用目前這個倉庫，而不使用 GitHub Classroom，也是可行的。你需要跟學生溝通一起完成哪一課。

在線上方式（Zoom、Teams 或其他）中，你可以為小測驗設立分組討論室，並指導學生準備學習。然後邀請學生在指定時間完成測驗並以「issue」提交答案。如果你希望學生公開協作完成作業，也可以採用同樣的方式。

如果你偏好較私密的形式，請學生將課程逐課分叉到他們自己的私人 GitHub 倉庫，並給你存取權限。然後他們可以私下完成測驗和作業，並透過你的課堂倉庫的 issue 提交給你。

有很多方法讓線上課堂能順利進行。請告訴我們何種方式對你最有效！
