## Untuk Pendidik

Apakah Anda ingin menggunakan kurikulum ini di kelas Anda? Silakan saja!

Bahkan, Anda bisa menggunakannya langsung di dalam GitHub dengan menggunakan GitHub Classroom.

Untuk melakukan itu, fork repo ini. Anda akan perlu membuat repo untuk setiap pelajaran, jadi Anda harus mengekstrak setiap folder menjadi repo yang terpisah. Dengan begitu, [GitHub Classroom](https://classroom.github.com/classrooms) dapat mengambil setiap pelajaran secara terpisah.

[Instruksi lengkap](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) ini akan memberi Anda gambaran bagaimana mengatur kelas Anda.

## Menggunakan repo apa adanya

Jika Anda ingin menggunakan repo ini dalam bentuk saat ini, tanpa menggunakan GitHub Classroom, itu juga bisa dilakukan. Anda perlu mengomunikasikan kepada siswa Anda pelajaran mana yang akan dikerjakan bersama.

Dalam format online (Zoom, Teams, atau lainnya) Anda mungkin membagi ruang breakout untuk kuis, dan membimbing siswa agar mereka siap belajar. Lalu undang siswa untuk mengikuti kuis dan mengirimkan jawaban mereka sebagai 'issues' pada waktu tertentu. Anda juga bisa melakukan hal yang sama untuk tugas, jika Anda ingin siswa bekerja secara kolaboratif secara terbuka.

Jika Anda lebih memilih format yang lebih privat, minta siswa Anda untuk melakukan fork kurikulum ini, pelajaran demi pelajaran, ke repo GitHub mereka sendiri sebagai repo privat, dan berikan Anda akses. Kemudian mereka bisa menyelesaikan kuis dan tugas secara privat dan mengirimkannya kepada Anda melalui issues di repo kelas Anda.

Ada banyak cara untuk membuat ini berhasil dalam format kelas online. Mohon beri tahu kami apa yang paling cocok untuk Anda!
