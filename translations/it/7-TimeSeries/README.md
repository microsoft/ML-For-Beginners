# Introduzione alla previsione delle serie temporali

Cos'è la previsione delle serie temporali? Si tratta di prevedere eventi futuri analizzando le tendenze del passato.

## Argomento regionale: consumo elettrico mondiale ✨

In queste due lezioni, verrà introdotta la previsione delle serie temporali, un'area del machine learning poco conosciuta ma estremamente preziosa per applicazioni industriali e commerciali, oltre che in altri campi. Sebbene le reti neurali possano essere utilizzate per migliorare l'utilità di questi modelli, le studieremo nel contesto del machine learning classico poiché i modelli aiutano a prevedere le prestazioni future basandosi sul passato.

Il nostro focus regionale è il consumo elettrico nel mondo, un dataset interessante per imparare a prevedere il consumo futuro di energia basandosi sui modelli del carico passato. Potrai vedere come questo tipo di previsione possa essere estremamente utile in un ambiente aziendale.
