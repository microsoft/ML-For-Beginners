# 时间序列预测简介

什么是时间序列预测？它是通过分析过去的趋势来预测未来事件。

## 地区主题：全球电力使用情况 ✨

在这两节课中，您将了解时间序列预测，这是机器学习中一个相对较少被人知晓但在工业和商业应用等领域极其有价值的部分。虽然神经网络可以用来增强这些模型的效用，但我们将以经典机器学习的视角来研究它们，因为模型有助于基于过去预测未来表现。

我们的地区关注点是全球的电力使用情况，这是一个有趣的数据集，用于学习基于过去负载模式预测未来的电力使用。您可以看到这种预测在商业环境中是多么有帮助。
