# Μηχανική Μάθηση για Αρχάριους - Ένα Πρόγραμμα Σπουδών

> 🌍 Ταξιδέψτε σε όλον τον κόσμο καθώς εξερευνούμε τη Μηχανική Μάθηση μέσα από πολιτισμούς του κόσμου 🌍

Οι Cloud Advocates στη Microsoft προσφέρουν ένα πρόγραμμα σπουδών 12 εβδομάδων με 26 μαθήματα που αφορά αποκλειστικά τη **Μηχανική Μάθηση**. Σε αυτό το πρόγραμμα, θα μάθετε για τη λεγόμενη **κλασική μηχανική μάθηση**, χρησιμοποιώντας πρωτίστως τη βιβλιοθήκη Scikit-learn και αποφεύγοντας το deep learning, που καλύπτεται στο [AI for Beginners' curriculum](https://aka.ms/ai4beginners). Συνδυάστε τα μαθήματα αυτά και με το ['Data Science for Beginners' curriculum](https://aka.ms/ds4beginners)!

Ταξιδέψτε μαζί μας σε όλον τον κόσμο εφαρμόζοντας αυτές τις κλασικές τεχνικές σε δεδομένα από πολλές περιοχές του κόσμου. Κάθε μάθημα περιλαμβάνει κουίζ πριν και μετά το μάθημα, γραπτές οδηγίες για την ολοκλήρωση του μαθήματος, λύση, άσκηση, και άλλα. Η παιδαγωγική μας με βάση έργα σας επιτρέπει να μαθαίνετε ενώ δημιουργείτε, μια αποδεδειγμένη μέθοδο για να "εγκαθίστανται" νέες δεξιότητες.

Ανοίξτε το πράσινο μενού **Code**, επιλέξτε **Codespaces**, και δημιουργήστε έναν codespace· εγκαταστήστε τις απαιτούμενες εξαρτήσεις κάθε μαθήματος μέσα σε αυτόν όσο χρειάζεται.

## Παιδαγωγική

Επιλέξαμε δύο παιδαγωγικές αρχές κατά την κατασκευή αυτού του προγράμματος: να είναι πρακτικό και **βασισμένο σε έργα** και να περιλαμβάνει **συχνά κουίζ**. Επιπλέον, το πρόγραμμα έχει ένα κοινό **θέμα** για συνεκτικότητα.

Διασφαλίζοντας ότι το περιεχόμενο ευθυγραμμίζεται με έργα, η διαδικασία γίνεται πιο ελκυστική για τους φοιτητές και η διατήρηση ενισχύεται. Επιπλέον, ένα χαμηλού ρίσκου κουίζ πριν τη τάξη θέτει την πρόθεση του φοιτητή να μάθει το θέμα, ενώ ένα δεύτερο μετά τη τάξη εξασφαλίζει περαιτέρω διατήρηση. Αυτό το πρόγραμμα σχεδιάστηκε για να είναι ευέλικτο και διασκεδαστικό και μπορεί να ληφθεί ολόκληρο ή μεμονωμένα μέρη. Τα έργα ξεκινούν μικρά και γίνονται ολοένα πιο πολύπλοκα μέχρι το τέλος του 12-εβδομαδιαίου κύκλου. Το πρόγραμμα περιλαμβάνει επίσης ένα επίμετρο για πραγματικές εφαρμογές της ML, που μπορεί να χρησιμοποιηθεί ως επιπλέον βαθμός ή ως βάση για συζήτηση.

> Βρείτε τον [Κώδικα Συμπεριφοράς μας](CODE_OF_CONDUCT.md), τους [Οδηγούς Συνεισφοράς](CONTRIBUTING.md), [Μεταφράσεις](..), και [Οδηγό Αντιμετώπισης Προβλημάτων](TROUBLESHOOTING.md). Καλωσορίζουμε τα εποικοδομητικά σχόλιά σας!

## Κάθε μάθημα περιλαμβάνει

- προαιρετικό σκίτσο
- προαιρετικό συμπληρωματικό βίντεο
- βίντεο με βήματα (μόνο σε μερικά μαθήματα)
- [προ-διάλεξη ζέσταμα κουίζ](https://ff-quizzes.netlify.app/en/ml/)
- γραπτό μάθημα
- για μαθήματα με έργα, οδηγίες βήμα προς βήμα για το πώς να φτιάξετε το έργο
- έλεγχοι γνώσης
- πρόκληση
- συμπληρωματική ανάγνωση
- εργασία
- [μετα-διάλεξη κουίζ](https://ff-quizzes.netlify.app/en/ml/)

> **Σημείωση για τις γλώσσες**: Αυτά τα μαθήματα είναι κυρίως γραμμένα σε Python, αλλά πολλά είναι διαθέσιμα και σε R. Για να ολοκληρώσετε ένα μάθημα R, πηγαίνετε στον φάκελο `/solution` και αναζητήστε μαθήματα R. Περιλαμβάνουν επέκταση .rmd που αντιπροσωπεύει ένα αρχείο **R Markdown**, το οποίο μπορεί να οριστεί ως ενσωμάτωση `code chunks` (R ή άλλων γλωσσών) και ενός `YAML header` (που καθοδηγεί τον τρόπο μορφοποίησης εξόδων όπως PDF) σε ένα `Markdown document`. Ως εκ τούτου, λειτουργεί ως υποδειγματικό πλαίσιο συγγραφής για data science, αφού σας επιτρέπει να συνδυάζετε τον κώδικά σας, την έξοδο και τις σκέψεις σας γράφοντάς τες σε Markdown. Επιπλέον, τα έγγραφα R Markdown μπορούν να μετατραπούν σε μορφές εξόδου όπως PDF, HTML ή Word.

> **Σημείωση για τα κουίζ**: Όλα τα κουίζ περιέχονται στον [φάκελο Quiz App](../../quiz-app), για συνολικά 52 κουίζ με τρεις ερωτήσεις το καθένα. Συνδέονται από τα μαθήματα αλλά η εφαρμογή κουίζ μπορεί να τρέξει τοπικά· ακολουθήστε τις οδηγίες στον φάκελο `quiz-app` για τοπική φιλοξενία ή ανάπτυξη στο Azure.

## Πώς να ζητήσετε βοήθεια

Εάν κολλήσετε ή έχετε ερωτήσεις ενώ μαθαίνετε Μηχανική Μάθηση ή δημιουργείτε εφαρμογές AI, μην αγχώνεστε — υπάρχει διαθέσιμη βοήθεια.

Μπορείτε να συμμετάσχετε σε συζητήσεις με άλλους μαθητές και προγραμματιστές, να κάνετε ερωτήσεις και να μοιραστείτε τις ιδέες σας με την κοινότητα.

- Γίνετε μέλος της κοινότητας για να κάνετε ερωτήσεις και να μάθετε με άλλους
- Συζητήστε έννοιες Μηχανικής Μάθησης και ιδέες έργων
- Λάβετε καθοδήγηση από έμπειρους προγραμματιστές

Μια υποστηρικτική κοινότητα είναι ένας εξαιρετικός τρόπος για να αναπτύξετε τις δεξιότητές σας και να λύσετε προβλήματα ταχύτερα.

[Κοινότητα Discord Microsoft Foundry](https://discord.gg/nTYy5BXMWG)

Εάν αντιμετωπίσετε σφάλματα, λάθη ή έχετε προτάσεις για βελτιώσεις, μπορείτε επίσης να ανοίξετε ένα **Issue** σε αυτό το αποθετήριο για να αναφέρετε το πρόβλημα.

Για ανατροφοδότηση προϊόντος ή για να αναζητήσετε υπάρχουσες αναρτήσεις κοινότητας, επισκεφτείτε το Developer Forum:
