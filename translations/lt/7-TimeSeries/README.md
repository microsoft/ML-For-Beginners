# Laiko eilučių prognozavimo įvadas

Kas yra laiko eilučių prognozavimas? Tai yra būsimų įvykių numatymas analizuojant praeities tendencijas.

## Regioninė tema: pasaulinis elektros vartojimas ✨

Šiuose dviejuose pamokose būsite supažindinti su laiko eilučių prognozavimu, santykinai mažiau žinoma mašininio mokymosi sritimi, kuri vis dėlto yra labai vertinga pramonės ir verslo taikymuose bei kituose sektoriuose. Nors neuroniniai tinklai gali būti naudojami šių modelių naudingumui didinti, mes juos studijuosime klasikiniame mašininio mokymosi kontekste, nes modeliai padeda numatyti būsimą našumą remiantis praeitimi.

Mūsų regioninis dėmesys skiriamas pasauliniam elektros naudojimui, įdomi duomenų rinkinio tema, leidžianti mokytis prognozuojant būsimą elektros vartojimą remiantis praeities apkrovos modeliais. Matote, kaip tokio tipo prognozavimas gali būti itin naudingas verslo aplinkoje.
